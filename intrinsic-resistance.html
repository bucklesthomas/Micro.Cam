Intrinsic resistance

Antibiotics each organism is expected to be resistant to, whatever the laboratory result. Look up by organism, or by antibiotic to see which organisms it will not cover.

Only intrinsic (expected) resistance is shown. An antibiotic not listed is not necessarily active: acquired resistance is common, so always use the isolate’s susceptibility results.

Source: EUCAST Expected Resistant Phenotypes, version 1.2 (2023), as encoded in the open-source AMR package, with notes from the EUCAST footnotes.
